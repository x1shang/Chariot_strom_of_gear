## 停用时的事实

- 归档日期 2026-10-17，来源提交 `c416898c3322f1742ddfac56a54ac7db6533da7c`，工作区干净。
- 电气侧：L298N 的 2 号通道（ENB=27、IN3=21、IN4=22）曾完成 6 次独立的 3000ms 电气正转与一次 10000ms 逆时针测试，1 号通道未做完整动作验收。**机械侧从未通过。**
- 机械侧：2026-10-14 实机试验四项失败（电池像是断路、3D 打印孔过大滑齿、卷线轴无半月形杆导致齿轮脱落、人力满行程下抛射角仍接近水平）；其后机构被扭矩破坏，电机被撕裂。以上均为用户现场口述，无仪器数据。
- 归档当时板上固件为 `MecanumPS2Dpad`（底盘方向键），本次方案变更后板上已改为 `FlywheelSpinTest`，**底盘在该固件下不行驶**。
- 串口由本文记录的 **COM9 变为 COM10**（同一颗 CH340，USB ID `1a86:7523`，MAC `08:a6:f7:a8:95:94` 未变）。

## 哪些内容继续有效

**只有驱动板与 GPIO 分配继续有效，并且已并入新方案文档**：L298N、ENA=14 / IN1=25 / IN2=26 与 ENB=27 / IN3=21 / IN4=22、12V 动力与 5V 逻辑分段、ENA/ENB 跳帽取下并各加 10kΩ 下拉、底盘 9 个 GPIO 与 PS2 四线不变。新文档在这些不变项之外，把「EN 只做开关」改为「EN 做 PWM 软启动」，并重写了负载电流、机械与安全要求。

**以下内容已作废**：卷线轴/齿轮/半月形杆的机械设计、1 号与 2 号的「蓄力/释放」职责、拉绳行程与限位、按旧机构的运行命令与验收步骤、原 `flash-catapult.ps1` 的 FOC 阶段。旧程序、脚本、仿真测试与全部日志保留在原目录用于追溯，三个 N20 模块 README 已标注停用。
