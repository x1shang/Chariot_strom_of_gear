## 覆盖的行为

启动按键保持不能直接运动、连续中立解锁、底盘极性/停止/换向等待；双飞轮软启动、单次10秒上限、松键停、早按送球不排队、按住不自动连发、N20限时/双向点动/间隔；行驶发射冲突锁定、无效或间断PS2帧/STOP停机、未知命令/缓冲溢出；舵机默认禁用、显式开启、脉宽边界、STOP冻结目标、独立频率；时间回绕、初始化及运行PWM失败，PWM停机写入失败时解除外设并尝试拉低引脚。

## 没有验证的事情

**本次未烧录、未打开串口、未运行任何电机或舵机。** 编译与仿真只证明源码能够构建及模拟条件下的控制行为，不能证明实际接线、电平波形、电机电流/温升、飞轮转速、送球数量、机构到位、舵机角度或平台扭矩。

默认预转2500ms、送球150ms/30%、间隔800ms、舵机1400–1600µs都需要现场标定。当前没有到位/转速/角度传感器接入，`pretime=1`不是实测转速，脉冲结束不是到位，舵机`us`不是角度。

当前旧硬件验收仍来自改线前的独立飞轮固件，不能沿用于新整合接线。请按[逐根线施工说明](../../发射装置改接线-从拔线到验收-2026-10-17.md)先逻辑检查、再分别加动力。
