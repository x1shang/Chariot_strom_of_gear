# v3.3 N20短点动诊断记录（2026-10-18）

当前固件 `ChariotIntegrated-v3.3-JOG` 已烧录COM4。792项主机模拟检查通过；ESP32 Arduino 3.3.12、esp32:esp32:esp32编译通过（程序289735字节，静态变量22576字节），上传校验通过。

- `host-tests.txt`：主机检查输出，不接硬件。
- `compile.txt`、`upload.txt`：本次编译、烧录记录。
- `off-50/`：全部电机动力断开，50%/150ms指令及自动停止核对。
- `powered-50/`、`powered-70/`：用户确认仅N20接通动力且脱离滑轨空载，各发送一次150ms点动。两次均有PWM/使能回读，均在主机STOP之前自动归零，无故障。用户两次均报告“没有转动，也没有声音”。
- `physical-observation.json`：单独记录用户现场观察。
- `verification.json`：当前源文件、测试、构建产物及日志SHA-256；构建产物仅记录哈希，不入库。四个固件源文件与本次编译暂存目录逐字节匹配。

N20故障尚未解决。PWM回读不能证明TB3端供电、电机端电压或电流；6V仅是降压板显示值。STBY下拉器件取下后GPIO使能恢复，仍未确定器件阻值及故障机制。R1默认仍为30%/150ms；单次JOG的第三参数不会修改该默认值。

飞轮两台130的输出线已经用户对调并确认方向正常。下一步断电核对TB3实际接线和供电，不把本记录当作整车验收。

复现脚本为 `host/jog_integrated_n20.py`。该脚本会发送电机动作命令：必须先按实际供电状态选择 `--power-state off` 或 `n20-only`，带电测试还必须确认空载；不要仅为重放日志执行。
