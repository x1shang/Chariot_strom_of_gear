## 证据边界（不要把这些写成已确认）

- `DUTY1/DUTY2` 是 `ledcRead()` 的**外设（已命令占空比）回读**，**不证明引脚电平、电机端电压或实际电流**；方向脚与 STBY 才是真实引脚电平回读。
- 本次**没有测量**任何机械量：130 电机是否已接到 OUT1/OUT2 与 OUT3/OUT4、是否真的转动、转向、转速、两侧是否对转、飞轮是否装好、有无异响与振动，全部需要现场观察。
- 本次**没有测量电流与温升**。飞轮启动是惯性负载、起始电流大，L298N 每路 2A 只是直流绝对最大额定值；提高占空比前必须先限流并监视电流与散热片温度。
- `d1=1 d2=1` 是**实验值**：两侧飞轮必须反向旋转才算有效发射方向，这一点尚未观察确认，不能写成「顺时针/逆时针已确认」。
- 撤销使能是**滑行停止**：`DONE`/`STOP` 之后飞轮仍在惯性旋转，不是已经停转。
- 本方案**没有编码器，没有转速或位置反馈**；旧 FOC 方案的 90° 定位/自动返回不再适用。

## 板上当前状态

板上固件为 `FlywheelSpin-v1`：只支持 `STATUS` / `STOP` / `DIR <d1> <d2>` / `SPIN [duty] [ms]`，每次上电只允许一次转动，两路 EN 默认 0。**底盘在该固件下不行驶**（STBY 全程为低、不含手柄控制）；要恢复行驶需重新烧录底盘固件（[MecanumPS2Dpad](../../../firmware/chassis/MecanumPS2Dpad/README.md) 或 `tools/build-chassis.ps1`）。
