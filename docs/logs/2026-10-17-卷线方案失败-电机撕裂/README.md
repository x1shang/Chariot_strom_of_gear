**归因边界**

用户把原因归为「扭矩太大」。从力学上说，卷线/蓄力机构把电机经齿轮与卷线轴**硬联到拉绳和限位端**，机构一旦到位或卡住，电机就进入堵转或冲击工况，此时反作用于电机与齿轮的力矩上限由**机构和限位**决定，而不是由电机决定——这与 2026-10-14 已记录的滑齿、齿轮沿圆轴脱落、限位器补救失败是同一类失效。**这是对用户原因的解释，不是本轮测得的结论**：真正的断口与失效顺序需要拆检才能认定。

## 6. 工程结论与对新方案的约束

摩擦飞轮方案把能量储存在**飞轮转子的动能**里，电机只承担惯性负载的加速力矩，机构中没有拉绳、齿轮组与硬限位，因此**不存在「到位即堵转」的工况**——这是选择该方案的力学理由。它同时给新方案留下三条硬约束：

1. **飞轮轮毂与紧固必须比旧卷线轴可靠**：圆轴配光孔齿轮的失效方式（沿轴向滑出）不能再出现；飞轮与电机轴必须用 D 形切面、紧定螺钉或夹紧轮毂等方式做**轴向与周向同时固定**。
2. **电机座的受力方向变了**：旧方案是齿轮啮合的径向力，新方案是飞轮旋转的不平衡力与启动反力矩；安装座与螺丝必须有防松措施（弹垫/螺纹胶），并且首次升速要**分级、短时、无人手持**。
3. **电流上限由电机与驱动板决定，不再由机构决定**：飞轮启动是惯性负载，启动电流大；原驱动板 L298N 每路 2A 是直流绝对最大额定值，不是长期能力。首次运行必须限流、分级、监视温升，见[新方案文档](../../抛投装置-双130摩擦飞轮接线与GPIO分配.md) §5。
