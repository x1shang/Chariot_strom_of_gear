# GPIO21使能修复与机构测试

v3.1曾在R1时feed=1但GPIO22回读0；全动力断开、GPIO22外线移除后仍为0。只能证明该次使能回读异常，未测定电压或证实芯片损坏。

飞轮：仅飞轮动力接通，用户按R2约2秒后松开，明确报告“两台都转，松开后逐渐停下”。这不是相向旋转或带球发射验收。

v3.2-STBY21将N20使能换到GPIO21，并增加使能拉高失败时撤销输出。691项主机检查、编译（程序289571字节，全局22576字节）、COM4烧录写入校验和USB启动通过。日志host-test-result.txt是对已观察测试输出的摘录，不是完整终端原始日志。

全部动力关闭、GPIO21未接外线时，手动R1采样多次见feed=1 TB3=1，随后均回到0，无FAULT。接回原STBY支路、全部电机动力关闭时，主机发一次JOG 1 100，触发FAULT feed enable，所有输出撤销；GPIO21接外线后不能拉高。说明外接支路负载/接线异常仍存在，尚未定位到电阻、导线或TB3本体。正在断电隔离STBY下拉；不得因此加大占空比或给N20通电。

首次使用新临时目录触发全量核心重编译，为节省时间取消该构建，随后改用已存在的ASCII缓存目录，compile.txt记录后者实际成功结果；未用取消的构建烧录。

GPIO21回读为MCU端逻辑电平，不能代替TB3端子实测电压。N20的电压、电流、方向与机械行程仍须现场确认。

## 隔离下拉后的结果

用户关闭全部动力、拔USB，将c23到d26那只STBY下拉的c23端拔出，再接USB。主机发一次JOG 1 100，出现feed=1 TB3=1且无FAULT，最后STOP归零。只说明该下拉器件/接法支路与低电平现象有关，未量出阻值，也未证明GPIO22损坏。

随后整只STBY下拉取下收好；GPIO21到STBY保持。用户仅恢复N20动力，点R1仍完全不动。再由主机执行一次JOG 1 300（30%，300ms）并STOP，feed=1 TB3=1、无FAULT，用户反馈“没有转动，也没有声音”。降压板显示屏用户读数6V，不代表已测到TB3 VM端电压。

当前N20实物测试尚未通过，待核对TB3 VM/VCC/GND/PWMA/AIN1/AIN2/AO1/AO2实际接线和动力。没有提高电压、没有提高占空比，也未证明电源、驱动板或电机中的任何一个已坏。试验结束已发STOP并回读零输出，已要求用户关闭全部电机动力。

STBY下拉目前是诊断性移除；原电阻及接法不要原样恢复。恢复经过确认的10kΩ下拉后，应在全部电机动力关闭时重新核对使能可拉高；未完成上电/断线失效检查，不作为最终全车验收。
