## 1. 仓库查到了什么

| 项目 | 仓库证据 | 本方案采用的判断 |
|---|---|---|
| 主控 | 试射记录为经典 ESP32-D0WD-V3，目标 `esp32:esp32:esp32` | 按现有 WROOM 类板的 GPIO 丝印接；不用 S3 排针图 |
| 飞轮 | L298N + 两台 130；`DIR 1 1`、100%/10 秒三次试射成功 | 沿用两台电机及四根输出线；固定方向对应原 `1/1` |
| 飞轮供电 | 用户报告 6V；端子实测、额定电压、电流未记录 | 保留现分支，先测量；不照历史文档调成 12V |
| 软启动 | `FlywheelSpinTest.ino` 中 5kHz、8bit、`RAMP_MS=1200` | 这是 ESP32 程序的 PWM 爬升，并非已证实飞轮自带软启动控制器 |
| 舵机 | [旧 GPIO 论证](麦轮TB6612接线-两线法备选方案.md)第 3.1 节提到物资表推荐 MG995/MG996R；仓库入口也提到 MG995 | 可按这类三线位置舵机规划 5V 分支，但没有实物型号/角度范围/堵转电流的确认记录 |
| N20 | 工作目录的 `n20-latest/docs/抛投装置-L298N双N20接线与GPIO分配.md`第 1 节明确：选用 12V 方案，具体型号、12V 额定连续运行依据、堵转电流未记录 | “原来接过 12V”不能证明新增 N20 应接 12V，也不能证明 TB3 电流够 |

舵机架的几何和无干涉检查不证明舵机电气型号。资产 OCR 中 2804 无刷电机的 12V、0.5A/2A 不能套到 N20。旧全车索引仍夹带 N20/12V、DRV8313/AS5600 历史表，本次改线以本文的新表为准；底盘第 3–9 排沿用原表。

## 2. 为什么能省出 GPIO

现飞轮占 6 个 GPIO：ENA=14、IN1=25、IN2=26；ENB=27、IN3=21、IN4=22。

两台飞轮在现有程序里本来就是同时爬升、同占空比。新方案把方向固定为原 `DIR 1 1`，两路 EN 合用 GPIO14：飞轮由 6 脚减至 1 脚，释放 5 脚。舵机使用 1 脚，N20 使用 2 个方向脚加 1 个独立 STBY，共用 4 脚，最后余下 GPIO21。

TB6612 是双路有刷直流电机 H 桥，**不能把普通三线舵机接到 AO1/AO2 或 BO1/BO2**。舵机内部已有驱动和位置控制，外部连接为信号、电源正极、地。一个 TB3 的 A 路即可控制 N20；B 路暂不用。

代价：两飞轮今后同开同关、同 PWM，占空比不能单独调整；相同 PWM 不保证转速相同。若需要分别校准两轮速度，需另行分配 GPIO，不能直接沿用本文。

## 3. 改接后的完整 GPIO 表

所有数字都是 **GPIO 丝印编号**，不是排针从上往下第几根。TB3 只是新板标签，不代表 ESP32 上名为 D3 的针脚。

| GPIO | 新用途 | 与现在相比 |
|---:|---|---|
| 16 / 17 | 底盘 D1 AIN1/AIN2，左前轮 | 保留 |
| 18 / 19 | 底盘 D1 BIN1/BIN2，左后轮 | 保留 |
| 23 / 32 | 底盘 D2 AIN1/AIN2，右前轮 | 保留 |
| 15 / 5 | 底盘 D2 BIN1/BIN2，右后轮 | 保留 |
| 33 | 仅底盘 D1、D2 STBY，原 10kΩ 下拉 | 保留；不接 TB3 STBY |
| 2 / 4 / 12 / 13 | PS2 CLK / CS / CMD / DAT | 保留；13 是输入 |
| **14** | **L298N ENA 与 ENB，共同飞轮 PWM** | ENA 保留，ENB 移入 |
| **27** | **舵机信号** | 从 L298N ENB 释放 |
| **25 / 26** | **TB3 AIN1 / AIN2，N20 正反转** | 从 L298N IN1/IN2 移出 |
| **22** | **TB3 STBY，独立 10kΩ 下拉** | 从 L298N IN4 移出 |
| **21** | **预留，暂不接** | 拆掉旧 L298N IN3 线；不用已知有故障历史的旧 SDA 线束 |

共用 18 个 GPIO：底盘 9、PS2 4、飞轮 1、舵机 1、N20 3。当前 19 个 GPIO 中腾出 1 个。

- 34、35、36(VP)、39(VN)：若板上引出且没有其他占用，可加限位/到位输入；不能当舵机或电机控制输出。这些脚没有可依赖的内部上下拉，开关输入需外加电阻。
- 0 留作启动；1/3 留作 USB 串口。6–11 是 Flash 相关脚，不改用。37/38 不作为本板可用排针规划。
- 2/5/12/15 含启动配置用途，已有接线保持；不要额外在这些脚加新负载或上下拉。
- TB3 虽还剩 B 路，但预留的一个普通输出脚不足以按同样方式新增一台完整双向电机。

## 4. 开始前准备

1. 新增 TB6612 模块一块，贴纸标 **TB3 / 弹匣**；底盘原板仍叫 D1、D2。
2. 给 TB3 STBY 新增 **10kΩ** 电阻一只；原 L298N 两个 EN 各自的 10kΩ 下拉保留。若原电阻未实际安装，先补齐，不能只看文档。
3. 准备可靠的电源分配端子、合适线径的电源线、绝缘材料。一个端子/孔只装它允许的线数，不能把两根线硬塞进一个杜邦孔。
4. 准备舵机独立稳压供电分支，本文标 `S5`；准备符合实物 N20 的动力分支，标 `N+`。两者尚未核实容量时不接负载正极。若现有电源没有空闲分支，先增加端子/稳压模块；不能凭空假定有第二个输出。
5. 本文把“公共地端子”称 `G0`：它是电源负极的分配点，舵机和电机的大电流直接回这里，不经 ESP32 或面包板。
6. 舵机须为可定位角度的版本；连续旋转舵机不直接等价于平台仰角控制。

**改任何一根线前：断开电池/外部电源、USB 和舵机电源，等待飞轮完全停下。** 给六根旧信号线贴标签 `14-ENA`、`25-IN1`、`26-IN2`、`27-ENB`、`21-IN3`、`22-IN4`；拍照留档。不要按线色认引脚。

## 5. 第一遍：只拆会冲突的旧线

| 步骤 | 原来的一根线 | 断电后怎么处理 |
|---:|---|---|
| 1 | GPIO27 → L298N ENB | **两端先拔掉**，收好。先解除 27 与 ENB 的连接，再合并 EN；否则会把 14、27 两个输出短接 |
| 2 | GPIO25 → L298N IN1 | 两端拔掉；稍后重用作 GPIO25 → TB3 AIN1 |
| 3 | GPIO26 → L298N IN2 | 两端拔掉；稍后重用作 GPIO26 → TB3 AIN2 |
| 4 | GPIO22 → L298N IN4 | 两端拔掉；稍后重用作 GPIO22 → TB3 STBY |
| 5 | GPIO21 → L298N IN3 | 两端拔掉，收好并标“预留/旧 SDA 线勿直接复用” |
| 6 | GPIO14 → L298N ENA | 保留功能；下一步改经分线排接到 ENA、ENB |

此时 L298N IN1–IN4 暂时都没有控制线，ENB 也不再接 GPIO27。检查旧 AS5600 或其专用上拉已从 21/22 拆除。**保持断电，不在中间状态试转。**

以下保留：底盘全部信号/电机线，PS2 全部线，L298N OUT1/OUT2 → 左130、OUT3/OUT4 → 右130 的四根线，L298N 已核实的供电与共地接法。飞轮电机线不交换。

## 6. 第二遍：按新孔位接信号

### 6.1 面包板位置约定

沿用仓库物理排号：a–e 同排相通，f–j 同排相通，中央隔槽两侧不通。底盘第 3–9 排不动；本次使用原设计空闲的 **20–24 排**，新增分配使用 **25、26 排**。开始前用断电通断档确认这些位置确实空闲；实物若已另有用途，不得覆盖。

左 `+` 轨仍仅由 **ESP32 3V3** 供电，左右 `−` 轨是逻辑 GND；右 `+` 轨保持空置。不要把 5V 舵机电源接进这些新信号排或 3V3 轨。下面新增的 26 排左右两组分别从地轨取电，**不增加跨中央槽的桥线**。

### 6.2 第20–26排，逐孔接

| 排号 | 每一根线的起点 → 终点 | 该排功能 |
|---:|---|---|
| 20 左组 | GPIO14 → **a20**；**d20** → L298N ENA；**e20** → L298N ENB | 两个 EN 由同一脚驱动；b20/c20留空 |
| 21 左组 | GPIO25 → **a21**；**e21** → TB3 AIN1 | N20 方向1；注意“第21排”不是 GPIO21 |
| 22 左组 | GPIO26 → **a22**；**e22** → TB3 AIN2 | N20 方向2 |
| 23 左组 | GPIO22 → **a23**；**b23** → TB3 STBY；**c23** → 新10kΩ电阻一端 | TB3 独立待机；电阻另一端接下表 d26 |
| 24 左组 | GPIO27 → **a24**；**e24** → 舵机 **S/Signal** 线 | 舵机信号，不能再通 L298N ENB |
| 25 左组 | 现有左3V3轨一个已测连通的空孔 → **a25**；**b25** → TB3 VCC；**c25** → TB3 PWMA；**d25** → L298N IN1；**e25** → L298N IN3 | 同源3.3V逻辑分配；五个孔各装一根线 |
| 26 左组 | 现有左GND轨空孔 → **a26**；**b26** → L298N IN2；**c26** → L298N IN4；新STBY电阻另一端 → **d26**；e26留空 | 方向固定低及 STBY 下拉地 |
| 26 右组 | 现有逻辑GND轨另一个空孔 → **f26**；**g26** → TB3 BIN1；**h26** → TB3 BIN2；**i26** → TB3 PWMB；j26留空 | 关掉不用的 B 路输入 |

原 ENA → 10kΩ → GND、ENB → 10kΩ → GND **两只电阻都保留在各自 EN 端**。合并后总下拉约 5kΩ，可以使用；不必拆掉其中一只。不要把 EN 直接短接 GND。

若新 TB3 板上有把 STBY 或 PWM 固定接高的跳帽/焊桥，先核对其电路，解除与本表冲突的连接；不按排针外观猜脚位。模块输入侧 VCC 用 3V3，VM 是电机动力，两者不能混接。

### 6.3 不经过面包板的电源与负载线

| 线号 | 起点 → 终点 | 接入条件/处理 |
|---|---|---|
| P01 | `N+` 动力源正极 → 该分支保险/断电开关 → **TB3 VM** | **电压、N20电流与TB3适配确认后接**；未知时绝缘悬空 |
| P02 | TB3 功率 GND → **G0** | 用独立电源线，不能借 GPIO 地细线承载电机电流 |
| P03 | `N+` 电源负极 → **G0** | 与 ESP32、L298N、底盘、舵机信号参考地共地 |
| P04 | TB3 **AO1/A01** → N20 两根电机线中的一根，贴 `M1` | 先与机构脱开，电机输出成对走电源线 |
| P05 | TB3 **AO2/A02** → N20 另一根电机线，贴 `M2` | `M1/M2` 不预先保证机械前进方向；低速单测后记录 |
| P06 | `S5` 稳压分支 OUT+ → 舵机 **V+/电源正极** | 规划5V；确认舵机型号、极性、峰值供电能力后接，不经过ESP32 5V针脚 |
| P07 | 舵机 **GND/电源负极** → `S5`负极分配端 / **G0** | 直接走电源回路，不经面包板地轨 |
| P08 | `S5` 负极 → **G0** | 若已为同一个公共负极端子，不重复编造第二个接口 |
| P09 | TB3 若另有逻辑GND脚 → 逻辑GND轨独立空孔 | 核实板上与功率GND连通；此线不替代 P02 |
| 不接 | TB3 **BO1/BO2** | 均悬空绝缘，不接舵机、不接地、不并到AO输出 |

三线舵机常见红=V+、黑/棕=GND、黄/橙/白=S，但必须由实物标识/手册确认，颜色只作辅助。舵机三针插头可接专用转接线/分配板；不要把整个插头跨插到相邻信号排。

L298N 的 **ENA/ENB 常高跳帽仍取下**。5V-EN 稳压跳帽是另一件事，按原已核实的外部逻辑 5V 方案处理。**固定高电平的 IN1/IN3 接 3V3 不代表把 L298N 的 5V/VSS 电源改成3V3。** L298N VS/`+12V` 丝印也不代表必须供12V。

## 7. 电源与驱动能力：哪些已确定，哪些还不能接电

| 分支 | 要求 | 当前结论 |
|---|---|---|
| ESP32/PS2/驱动逻辑 | 沿用原供电，3V3轨只有一个来源 | 新TB3仅加逻辑负载，仍需测负载下3V3；不能并入降压模块另一路3V3输出 |
| 飞轮 | L298N逻辑稳定5V；动力保持已用分支，记录实际VS与电机端电压 | 本次不根据旧N20文档改压；已有三次短试射，电流/温升仍未测 |
| N20 | 按实物额定电压选 `N+`；电机启动/堵转和工作电流须落在TB3及电源能力内 | 精确型号、电流未找到，**P01暂不接**；不能仅凭“N20”判断TB6612够用 |
| 舵机 | 按实物电压、堵转电流和平台负载选 `S5`，确认S输入接受3.3V信号 | 仓库只有MG995/MG996R推荐；规划独立稳压5V，现有降压模块是否够电流未记录，**P06暂不接** |

Tower Pro 当前 MG996R 页面给出的工作范围为4.8–6.6V，5V可作为这一型号的规划值；这不确认手里的舵机就属于该版本，也不证明现有5V输出可带它。[原厂MG996R](https://towerpro.com.tw/product/mg996R/)

舵机S输入若不能接受3.3V，先选定合适的单向电平转换器并补接线表，不能把5V直接接回GPIO27。信号核查阶段可先拔下舵机端S线，在开路信号端测脉冲，避免给未供电的舵机灌入信号电流。

TB6612官方当前手册（落款2026-05-13）正常工作范围写明：VM=2.5–13.5V，VCC=2.7–5.5V；每路输出在VM≥4.5V时为1.0A，较低VM段另有0.4A限制及表内条件。**1.2A属于绝对最大额定项，3.2A是规定条件下10ms单脉冲，均不能当持续或长启动电流保证。** 设计还受商品模块更严格的电压限制、散热及去耦约束；按模块资料检查VM/VCC旁的去耦电容。没有主动限流的TB6612，不会因为接上小尺寸N20就自动安全。[TB6612手册，第3、7页](https://toshiba.semicon-storage.com/info/TB6612FNG_datasheet_en_20141001.pdf?did=10660&prodName=TB6612FNG)

若N20电流超出适配范围，应换有合适电流能力/限流功能的驱动，不能硬试、并联A/B输出或用软件占空比冒充电流保护。不要手掐电机做堵转测量；先查实物规格，必要时在独立限流试验条件下测启动/工作电流。

平台仰角能否达到目标还取决于舵机扭矩、重心到转轴的距离和连杆几何。先估算最不利姿态的重力矩并留裕量，设置机械支撑/限位；不能拿标称堵转扭矩当持续保持能力。避免让舵机承担飞轮轴的径向载荷，调角机构与飞轮轴承各自支撑。

## 8. 飞轮“给电/不给电”怎样保留软启动

上层仍可只有“开”和“关”，但“开”在程序内部必须经过：

`待机（PWM=0） → 预转（PWM从0逐渐升到目标） → 等待转速稳定 → 允许N20送弹 → 撤销送弹 → 按需关闭飞轮`

- GPIO14继续输出 **5kHz PWM**。原1200ms爬升可作初始试验参数，不改成直接 `digitalWrite(14,HIGH)` 的满压硬启动。
- 软启动通常有助于减轻冲击，但没有电流测量/闭环时**不是限流器**；不能用“占空比×堵转电流”当真实启动电流上界。低占空比卡住、负载过大时也可能过流。
- 爬升结束只表示PWM已到目标，不证明飞轮已达到工作转速。需现场验证预转时间；若加转速反馈，按转速允许送弹。不能直接把1.2秒定为必然可发射时间。
- 连续发多球时可保持飞轮工作，N20按每次送弹动作启停，并留转速恢复时间。每球都断电重启会重复经历软启动，节拍通常更差。
- “关”令PWM=0、停止主动驱动。飞轮仍会滑行，**不给电不等于瞬间不转**，也不是电源物理隔离；真正要防接触/检修时用动力断电开关并等待完全静止。
- 共用EN意味着同一占空比，不能独立补偿两轮；当前试射`1/1`只是两桥IN电平组合，不等于两台电机都从同一观察方向顺时针。按球道确认两侧摩擦面均把球送向出口。

## 9. N20动作与到位

TB3 STBY=0 时A/B输出待机；STBY=1、PWMA=3V3时：AIN1=1/AIN2=0与0/1分别是两种电气方向；两IN=0为高阻停止。机械对接/退回方向必须实测标记。

25/26既可普通数字正反转，也可由固件在IN脚做PWM以低速点动；进行PWM时一个IN输出PWM、另一IN保持0。换向先关STBY/清零，停止后再切方向。**TB3 STBY必须独立接22**：如果也接底盘33，车停下时N20就会被一起禁用，无法在停车状态送弹。

弹匣“对接到位”是位置需求，定时转若干毫秒不能可靠判定到位。先机械脱开验证电气方向；接机构后应采用到位开关/编码器或已经验证的机械定位方案，另设运行超时，禁止顶住硬限位继续供电。

可选但本次不强行增加的限位接口：GPIO34和35各接一个干接点开关，公共端接逻辑GND，信号各经外部10kΩ上拉至3V3，并做去抖/断线检查。板上是否有34/35、开关NO/NC接法及位置确认后另补实物线表；这些输入不占本文剩余输出21。若N20带编码器，不能把编码器电源线误接AO输出。

## 10. 配套固件与接电前要求

**`FlywheelSpinTest`、旧N20测试程序、`MecanumPS2Dpad`均不是本表的整合固件。** 旧飞轮程序会在27输出5kHz、并控制25/26/22；新接线下这些脚已经成了舵机/N20，不能运行原程序。使用本次新增的[ChariotIntegrated-v2](../firmware/robot/ChariotIntegrated/README.md)，按“傻瓜式施工说明”先断动力烧录，再分机构测试。软件仿真/编译不代替实物验收。

| 资源 | 新分配建议 | 要点 |
|---|---|---|
| 底盘8个IN PWM | LEDC CH0–7，20kHz/8bit | 保留原底盘行为 |
| 飞轮GPIO14 | CH8，5kHz/8bit | 只挂一个GPIO，硬件分到两个EN |
| 舵机GPIO27 | CH9，通常50Hz/16bit，最终按实物手册 | 与飞轮使用不同频率配置；脉宽按舵机验证，不照抄电机PWM |
| N20 GPIO25/26 | 如需低速PWM，用CH10/11，20kHz/8bit | 仅开关时可数字输出；IN不同时驱动两个方向 |

经典ESP32有16个LEDC通道。当前本机Arduino-ESP32 **3.3.12** 会在同组寻找相同频率/分辨率的定时器或空闲定时器；上表资源足够，但必须逐项检查初始化返回值与频率。不要再让自动分配通道的舵机库覆盖这些资源；不能把旧飞轮测试的CH0/1直接拼进底盘代码。[官方LEDC说明](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/ledc.html)

本次程序的行为与仍需落实的条件：

1. 启动/复位先令14=0、22=0、25/26=0、33=0；启动不送弹、不自动升速。舵机初始化不能跳向未知极限，先脱开连杆核对中位。
2. 飞轮软启动采用非阻塞计时，不能用长`delay()`妨碍PS2轮询、停止或看门狗。
3. 手柄松键并右摇杆回中后自动就绪，失联/停止立即禁止送弹并关闭飞轮驱动。舵机保持安全角度或停脉冲须结合平台支撑验证，不能因断信号而让平台下坠。
4. 送弹要求停车、舵机指令已稳定、飞轮已预转。调仰角与发射冲突会停机锁定。2.5秒预转、800ms两次送球恢复间隔是试验初值，不是转速实测；舵机稳定只指脉宽指令已稳定。
5. N20默认30%/150ms单次送球脉冲，调试点动最长500ms，不能一直按键连发；停止/失联可中断。**当前没有到位/编码器输入，尚未实现传感器到位停止或卡弹识别**；精确定位应补传感器或经验证的机械定位方案，不能把脉冲结束当到位。
6. 保留现LEDC满输出写255/可能回读256的处理经验，不能把原始回读数字当实际电机电压、转速或输出波形。

## 11. 实施和验收顺序

### A. 全断电检查

- [ ] 拍照、标签、核对TB3丝印；20–26排实际空闲、行内连通且相邻排不短路。
- [ ] 27与ENB已断开；14只连两EN，不与27连通。
- [ ] L298N IN1/IN3接3V3，IN2/IN4接GND；ENA/ENB跳帽取下，两个10kΩ下拉存在。
- [ ] 25/26只连TB3 AIN1/AIN2；22只连TB3 STBY及其10kΩ下拉；不连L298N旧IN脚。
- [ ] TB3 VCC/PWMA是3V3；VM与VCC没有误接；B路输入接地，输出悬空。
- [ ] 舵机S接27，V+不接GPIO、3V3轨或H桥输出；功率回流直接回G0。
- [ ] N20型号/额定电压/电流、舵机型号/电压/峰值电流、分支容量已记录；未确定时P01/P06仍断开。

通断蜂鸣只用于查线和明显误短接，不把经过芯片的某次蜂鸣当唯一故障判断。核对10kΩ阻值时需要至少抬起一端；在线可能读到并联值。

### B. 固件与逻辑先行

1. 先完成整合固件的编译和必要软件检查。烧录时四轮、飞轮、N20动力和舵机电源均关闭；USB已接，外部5V到ESP32的正极隔离，避免回供电。
2. 按第5–6节改线后，仅给已核实的逻辑电源。N20和舵机电源仍断开，先检查ESP32 3V3轨、TB3 VCC/PWMA约3.3V。
3. 在模块端黑表笔接GND：静止时L298N两EN约0V，TB3 STBY约0V、AIN1/AIN2约0V；固定IN1/IN3约3.3V、IN2/IN4约0V。异常即断电查线。
4. 按一次复位，重复检查默认禁用。舵机50Hz脉冲和飞轮PWM用示波器/逻辑分析仪确认；万用表平均电压不能证明频率/脉宽正确。

### C. 分别接动力，不同时试全部机构

1. **舵机单测**：其他动力关闭，卸下连杆/舵盘负载并支撑平台；确认S5空载电压、极性和限流设置后才接P06。按该舵机安全脉宽从中位附近小幅运动，记录实际方向、5V末端压降/峰值电流。不要直接扫0–180°或强推极限。中位与机械安全位置一致后再装连杆，逐步标定仰角范围。
2. **N20单测**：舵机电源及其他动力关闭，N20与机构脱开；适配条件满足后才接P01。新固件低占空比短点动，先测一个方向，再停止后测另一个，记录M1/M2、机械对接/退回方向、电流。接机构后逐项验到位、超时、卡滞停机。
3. **飞轮单测**：其他动力关闭、无球，保持现两台130输出线；核对VS和逻辑5V，低占空比开始验证共EN同时起停/软启动，确认出口方向、电流、温升及振动。不能把已有三次试射自动算作本次改线后的验收。
4. **集成**：先停车，调角并等待，飞轮预转，最后允许单次送弹。记录实际仰角、预转/恢复时间、送弹到位和是否有主控复位。随后验证松键/停止、手柄失联、复位、超时，均会撤销不应继续的驱动。
5. 任何接线松动、冒烟、明显异常温升、持续嗡鸣不动、严重振动、掉电复位或到位不停，立即物理断动力。飞轮滑行完全停止后再检查，不带电拔插。
