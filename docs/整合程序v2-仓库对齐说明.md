## 对前一版的修正

| 项目 | v1桌面包 | v2，按仓库修订 |
|---|---|---|
| 飞轮按键 | 方框 | **R2**，松开撤销飞轮/N20输出 |
| 额外解锁 | 需要START | **不需要START/L1**；中立条件满足自动就绪 |
| 转向 | 只有方向键平移 | **恢复右摇杆横轴比例转向**，可与方向键叠加 |
| 模式协商 | 无 | 启动发送PS2X兼容协商；数字模式下只在静止且无按键时每2秒重试 |
| 中立判据 | 按键松开 | 按键松开并且右摇杆回中；数字模式忽略尾部摇杆字节 |
| 驾驶与飞轮 | 同时动作会锁定 | **允许驾驶时预转飞轮**，与仓库操作一致 |
| N20送球 | 方框预转后按叉 | **R2预转后按叉**；方向键松开、右摇杆回中、底盘输出关闭才接受，行驶时请求拒绝且不排队 |
| 调仰角 | 停车调整 | 保留；与行驶、飞轮或送球冲突时停机锁定 |

R2与方框不是别名：v2方框不启动飞轮，避免两套操作混用。START也不再切换发射解锁。串口ARM仅保留兼容用途，不是使用手柄前的必做步骤。

## 保留已确认的新方案

**GPIO不改变，已经按新表拆线/接线的部分不用重来：** GPIO14→L298N双EN；25/26/22→TB3 AIN1/AIN2/STBY；27→舵机S；21预留；底盘/PS2原接法保留。

远程MecanumPS2Flywheel-v2仍按旧六线飞轮接法，R2直接给恒高、没有软启动或单次时限。不能原样复制其接线常量和整个初始化到新方案。因此v2整合程序只迁移现有驾驶/手柄协议和操作习惯，继续保留：

- 新GPIO分配与N20独立STBY，不写旧飞轮方向GPIO。
- 飞轮5kHz、1200ms爬升到100%、预转许可2500ms、单次最多10秒。单次超时要松R2再按，非无限运转。
- N20默认150ms/30%单脉冲、最长500ms调试点动、两次停止间隔800ms；没有到位反馈，不保证单颗球或机械到位。
- 舵机上电禁用、SELECT显式启用、L1/R1调整，初始1400–1600µs，需卸连杆标定。
- STOP/圆圈/无效帧/150ms间断帧撤销电机输出；舵机冻结最后脉宽指令。若无线接收器重复旧有效帧，程序不能仅靠串口帧识别无线侧失联，需现场验证。
