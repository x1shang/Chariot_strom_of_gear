## 1. 为什么改成摩擦飞轮

| | 旧方案（已停用） | 新方案 |
|---|---|---|
| 储能方式 | 拉绳 + 抛杆（势能），经齿轮与卷线轴驱动 | 两个飞轮转子的动能 |
| 电机负载性质 | **硬联到拉绳与限位端**：到位或卡住即堵转/冲击 | 惯性负载：只有加速飞轮的力矩，无硬限位反冲 |
| 失效模式 | 齿轮滑齿、齿轮沿圆轴脱出、**扭矩过大把电机撕裂** | 待验证；风险转移到轮毂紧固、动平衡与驱动板电流 |
| 力矩上限由谁决定 | 由**机构与限位**决定，可以远超电机能力 | 由电机自身的转矩—转速特性决定 |

旧方案把电机经齿轮与卷线轴硬联到拉绳和限位端时，机构一旦到位或卡住，反作用于电机与齿轮的力矩上限就由机构决定，而不是由电机决定——这是「电机被撕裂」的力学来源。飞轮方案把能量存进转子动能，**没有拉绳、没有齿轮组、没有硬限位**，因此不存在「到位即堵转」的工况。这也是选择该方案的唯一理由；它并不自动解决装配与电流问题。

### 机械职责（本次定义）

| 电机 | L298N 通道 | 输出端子 | 机械职责 |
|---|---|---|---|
| **130-1** | A | OUT1 / OUT2 | 左飞轮，靠摩擦面把球推出 |
| **130-2** | B | OUT3 / OUT4 | 右飞轮，与左飞轮**反向旋转**，两侧同时夹住球加速 |

两轮之间是球的通道（摩擦道）。**两侧飞轮必须反向旋转**，否则球不会被推出而是被抛回或卡住。飞轮与球之间的压力、间隙与压入量决定摩擦力，属机械设计，本轮未确定。

## 2. L298N 信号分配（沿用原接线，EN 改为 PWM）

物理接线**不变**，仅语义与用法改变：原来 EN 只当开关用（全程常高），现在 **EN 作为 PWM 调速/软启动脚**使用。表中数字是 GPIO 丝印编号，不是排针位置，也不是 L298N 封装脚号。

| L298N 模块端子 | ESP32 GPIO | 用途 | 接线要求 |
|---|---:|---|---|
| ENA | **14** | 130-1 PWM 使能（软启动/调速） | 取下 ENA 常高跳帽；经独立 10kΩ 下拉到 GND |
| IN1 | **25** | 130-1 方向信号 1 | 直接接 3.3V GPIO 信号 |
| IN2 | **26** | 130-1 方向信号 2 | 直接接 3.3V GPIO 信号 |
| ENB | **27** | 130-2 PWM 使能（软启动/调速） | 取下 ENB 常高跳帽；经独立 10kΩ 下拉到 GND |
| IN3 | **21** | 130-2 方向信号 1 | 检查原 SDA 线束故障；不再连接 I2C |
| IN4 | **22** | 130-2 方向信号 2 | 不再连接 I2C |
| OUT1 / OUT2 | 不接 GPIO | 接 **130-1** 两根电机线 | 一路桥只接一台电机；输出不接系统 GND |
| OUT3 / OUT4 | 不接 GPIO | 接 **130-2** 两根电机线 | 同上 |

固件常量（与旧方案逐字相同，只是名字改了）：

```cpp
constexpr uint8_t FW1_EN = 14, FW1_IN1 = 25, FW1_IN2 = 26;   // OUT1/OUT2 -> 左飞轮
constexpr uint8_t FW2_EN = 27, FW2_IN3 = 21, FW2_IN4 = 22;   // OUT3/OUT4 -> 右飞轮
```

ST 数据手册规定 L298 的方向及使能输入高电平门限为 2.3V，芯片逻辑电源典型为 5V；ESP32 的 3.3V 控制信号可驱动其标准输入，**但 L298N 逻辑供电仍需 5V，不能用 ESP32 3V3 代替**。商品模块如另有输入电路，以实物模块说明为准。[ST L298 数据手册，表 4](https://www.st.com/resource/en/datasheet/l298.pdf)

## 3. 全车 GPIO 冲突核对（不变）

| 子系统 | GPIO / 固定接法 |
|---|---|
| 底盘左前 FL | 16 / 17 |
| 底盘左后 RL | 18 / 19 |
| 底盘右前 FR | 23 / 32 |
| 底盘右后 RR | 15 / 5 |
| 两块 TB6612 共用 STBY | 33，保留 10kΩ 下拉 |
| PS2 CLK / CS / CMD / DAT | 2 / 4 / 12 / 13 |
| 抛投 130-1：ENA / IN1 / IN2 | 14 / 25 / 26 |
| 抛投 130-2：ENB / IN3 / IN4 | 27 / 21 / 22 |

共 19 个互不重复的 GPIO：底盘 9 个、PS2 4 个、抛投 6 个。**本次方案变更没有增减任何 GPIO，也没有挪动底盘与手柄接线**——新增的只有「EN 变 PWM」这一点用法差异。

PWM 资源（LEDC）需要单独交代：底盘八路在 `MecanumPS2Dpad` 中用 20kHz / 8bit、通道 0–7。飞轮测试固件是**独立固件**（底盘 STBY 全程为低），使用通道 0 / 1、5kHz / 8bit，因此与底盘不冲突；**将来把两者整合进同一固件时，必须重新统一分配通道与定时器**，不能沿用本固件的通道号。

## 4. 供电（延续原方案，不新增改动）

| L298N 电源端子 | 接法 |
|---|---|
| VS / 模块标注的 +12V | 合适的动力源 → 保险丝 / 物理断电开关 → L298N 动力正极 |
| GND | 直接回公共地端子，与 ESP32 GND、逻辑 5V 负极及底盘共地 |
| 5V / VSS | 确认模块允许外部逻辑供电后，用独立稳定 5V；先按模块说明禁用板载 5V 稳压器 |

模块的 **5V-EN / 板载稳压跳帽**与 **ENA、ENB 通道跳帽**用途不同。外接逻辑 5V 前确认稳压器已按要求隔离，不能把板载 5V 输出与外部 5V 并联；不要由 L298N 的 5V 端给 ESP32 回供电。底盘保留与其电机匹配的独立动力分支（TT 额定 3–6V），**只有抛投分支沿用原 12V 分支设置**。

## 5. 130 电机规格与电流——本次最大的未知

**130 只是外形尺寸代号，不是电压等级。** 实物铭牌、额定电压、空载转速、堵转电流、减速比（如有）**本轮全部未记录**，所以：

- 常见 130 玩具电机是低压型，若直接对 12V 分支满占空比运行，可能远超其额定电压；也存在 12V 版本。**在确认铭牌之前，不得把 12V 写成 130 电机的额定值。**
- 飞轮启动是惯性负载：起始电流接近该电压下的堵转电流，随转速上升而下降。这也是本次测试**必须软启动 + 限占空比**的原因。
- L298 每路 2A 是**直流绝对最大额定值**，不是商品模块可长期承受的电流；1A 时数据手册给出的典型总导通压降约 1.8V，12V 输入不代表电机端恒定 12V。[ST L298 数据手册，表 1、表 4](https://www.st.com/resource/en/datasheet/l298.pdf)

**因此首次带载运行的硬要求：** 使用可限流的动力源（或串入熔断器 + 电流表），从低占空比开始，逐级升速并**同时监视电流与 L298N 散热片温度**；一旦电流接近模块能力或温升明显，立即停止并重新评估驱动方案（用户本次要求沿用原驱动板，若实测超限需更换更高电流的 MOS 驱动，属方案调整而非故障）。

## 6. 电机方向与「对转」确认

两侧飞轮必须反向旋转，但**电机装在左右两侧时，「电气正转」与「观察到的旋转方向」的关系由接线与安装方式共同决定，本轮未确认**。确认步骤：

1. 断开动力，只保留 USB 与逻辑 5V；确认两个 EN 回读为 0。
2. 上电后发 `STATUS`，确认 `hw=1 used=0 d1=1 d2=1 DUTY1=0 DUTY2=0 STBY=0`。
3. 用 `DIR <d1> <d2>` 设定四种极性组合之一；**先用最低占空比、最短时间分别单侧试转**（`SPIN` 的占空比参数），从外侧观察两个飞轮的转向。
4. 目标是**两轮在球道两侧呈对转**（球被夹住后向出口方向加速）。把观察结果记入记录文件；在确认之前，`d1`/`d2` 都是实验值，不能写成「已确认顺时针/逆时针」。
5. 确认后的极性组合写进本文与固件 README 的「已确认」栏，并据此固定接线。

## 7. PWM 频率、软启动与占空比上限（本次的设计取舍）

| 项目 | 取值 | 理由 |
|---|---|---|
| PWM 频率 | **5000 Hz** | L298 是双极型桥，开关沿较慢、开关损耗随频率上升；20kHz 级对它有明显损耗与发热风险。5kHz 兼顾平滑度与损耗。底盘用的 20kHz 是 TB6612（MOS 输出）的取值，不能照搬到 L298 |
| 分辨率 | 8 bit（0–255） | 与底盘固件一致，8bit 在 5kHz 下足够 |
| 软启动 | 0 → 目标占空比，**1200ms 线性爬升** | 起始时刻的平均电压被占空比压低，起始电流约为「该占空比 × 堵转电流」，而不是满压堵转电流；飞轮缓慢升速即可把冲击电流摊到整个爬升过程 |
| 默认占空比 | **30%** | 首次空载测试值，不假定电机额定电压 |
| 占空比上限 | **60%（固件硬限）** | 首次测试的保守天花板；提高需要**有意识地**改固件常量并重新编译，不做成运行时可调 |
| 单次时长上限 | 10000 ms（默认 3000ms，含爬升） | 限制堵转与温升风险；130 飞轮不需要长时运行 |
| 每次上电可运行次数 | **1 次** | 与旧测试固件一致：上电静止，执行过或中途停止后拒绝重复，必须复位 |

固件在目标占空比保持的这段时间里打印运行状态，退出时先撤销两路使能再打印 `COAST`：**`COAST` 表示电气输出已撤销、飞轮靠惯性继续旋转，不是已经停转。**

## 8. 机械与装配要求（新方案的主要风险点）

旧方案的失效方式（滑齿、齿轮沿圆轴脱出、电机被撕裂）在飞轮方案里的对应风险是：**飞轮从电机轴脱出**、**动平衡差导致振动把安装座震松**、**安装座承受不住启动反力矩**。因此：

1. **周向 + 轴向同时固定**：飞轮轮毂与电机轴之间用 D 形切面 / 紧定螺钉 / 夹紧轮毂，至少两处；严禁只靠过盈或胶水。旧卷线轴的圆轴光孔配合是明确的反面案例。
2. **防松**：所有紧固件用弹垫或螺纹胶；飞轮螺母旋向应考虑旋转方向（避免运转中自松）。
3. **动平衡**：飞轮尽量对称、少偏心；有明显振动时降速并重新配平，不要靠加速「压过去」。
4. **电机座**：安装座要固定到机架而不是悬臂；首次升速时不得手持机构。
5. **护罩/隔离**：飞轮旋转面加简易护罩或隔离结构，人不得进入飞轮平面。
6. **通道与间隙**：两轮夹持球的间隙与压入量需可调，否则摩擦不足（打不远）或阻力过大（丢转速）。

以上全部为**待装配验收项**，本轮没有做。

## 9. 安全红线

- **飞轮是储能件**：断电后仍会继续旋转一段时间，禁止用手或其他物体接触正在旋转或刚停下的飞轮，也不要试图用手「按住」飞轮减速。
- 运行前确认护罩、护目镜、周围无人员和易飞物；**上电与发命令时人必须在场**。
- 动力侧要有**物理断电开关**，不要只靠串口 `STOP`。
- 固件保证：上电静止、每次上电只允许一次转动、EN 默认低、命令溢出即停、GPIO 回读不符即锁定 `hw=0` 并撤销输出、1 秒任务看门狗。
- 烧录、接线、拔插杜邦线时**必须关闭动力**，只保留 USB 与逻辑 5V。
- 撤销使能是**滑行停止**，不保证抱死，也没有位置/速度反馈（本方案没有编码器，与旧 FOC 方案不同）。

## 10. 测试固件与命令

固件：[`firmware/catapult/FlywheelSpinTest`](../firmware/catapult/FlywheelSpinTest/README.md)，串口 115200，命令以换行结束：

| 命令 | 作用 |
|---|---|
| `STATUS` | 版本、`hw`、`used`、`d1/d2`、两路 EN 占空比回读、四个方向脚、STBY、计时 |
| `DIR <d1> <d2>` | 设定两路极性（各取 1 或 -1），不产生运动；运行后不可再改 |
| `SPIN <duty> <ms>` | 两侧同时软启动到目标占空比并保持，到时关断。缺省 `30 3000`；占空比限 1–60(%)，时长 ≤10000ms。**每次上电仅一次** |
| `STOP` | 立即撤销两路使能并停止保持（飞轮滑行） |

主机侧单次执行工具：[`host/flywheel_spin_once.py`](../host/flywheel_spin_once.py)（执行前核对状态、只发一次、退出时必发 `STOP`、不重试）。主机侧仿真测试：[`tests/test_flywheel_spin_firmware.cpp`](../tests/test_flywheel_spin_firmware.cpp)。

## 11. 验收顺序（下一步按此推进）

1. **断电核对**：两路 EN 跳帽已取下、各 10kΩ 下拉、共地、5V 逻辑供电、130 电机确实接在 OUT1/OUT2 与 OUT3/OUT4。
2. **逻辑核对**：上电只保留逻辑供电，`STATUS` 应报 `hw=1 used=0 DUTY1=0 DUTY2=0 STBY=0`。
3. **单侧低速试转**：确认每个飞轮都能转、转向可辨、无异响与明显振动。
4. **双侧低速对转**：确认两轮对转方向正确，记录极性。
5. **逐级升速**：30% → 45% → 60%，每级记录电流、温升、振动与听觉表现；发现异常立即停。
6. **加球试射**：仅在第 5 步全部正常、且机械护罩到位后进行；记录投出距离与角度（这才是本机构真正的验收指标）。
7. **底盘整合**：把两路 EN 的 PWM 通道与底盘八路统一分配后并入行驶固件，并加互锁（行驶与发射不同时动作）。
