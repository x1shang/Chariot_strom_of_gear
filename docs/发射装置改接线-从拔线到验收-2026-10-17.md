# 从拔旧线到接新线：双130飞轮 + N20送球 + 仰角舵机

> **2026-10-18当前操作以[v3-R1对接器说明](整合程序v3-R1对接器-2026-10-18.md)为准：** 用户已报告完成接线；本次无舵机，R1改为独立定时N20，R2控制飞轮。本页以下保留最初施工背景，舵机步骤跳过，旧v2按键不适用。

日期：2026-10-17。配套程序：`ChariotIntegrated-v2`。**v2按远程仓库恢复R2飞轮、右摇杆转向和中立后自动就绪；GPIO表不变。**只适用经典ESP32和本仓库现有底盘/PS2接法。

**照着做的目标：两台130仍接原L298N；N20接新增TB6612（贴“TB3”标签）；舵机信号接GPIO27。底盘和PS2不挪线。**

**这是施工说明，不是已经完成的实物验收。程序已经编写，验证结果看随包“验证记录”。本次没有烧录或启动电机。** 电机型号/电流和舵机供电能力在仓库没有完整记录；电源正极接入条件未满足的步骤，停在该步，不猜电压。

## 第0步：先认清楚三块板和这些名字

| 贴纸名 | 实物 | 这次做什么 |
|---|---|---|
| D1、D2 | 现有两块底盘TB6612 | 保持原样，不拔它们的线 |
| 飞轮板 | 现有L298N，接着两台130 | 改四根方向信号和一根ENB信号 |
| TB3 | 新增/空闲的TB6612 | 只用A通道接送球N20 |
| ESP32 | 已用主控板 | 按板上GPIO数字找脚，不数排针位置 |

- `3V3`是ESP32的3.3V逻辑输出；`GND`是地。**后面IN1/IN3接3V3，只是方向信号，电机动力绝不是由3V3供给。**
- TB3的`VCC`是逻辑电源，`VM`是电机动力；不能互换。`AO1/AO2`也可能印`A01/A02`。
- L298N的`ENA/ENB`是通道使能，`IN1–IN4`是方向，`OUT1–OUT4`接电机。`5V-EN`跳帽和`ENA/ENB`跳帽是不同东西。
- 本说明的“左+轨”是原ESP32 3V3轨，“左/右−轨”是原逻辑地。右+轨继续不接电。
- `G0`是现有公共电源负极分线端子。电机、舵机的大电流要用电源线回G0，不让它经过面包板和ESP32细地线。

## 第1步：全部断电，拍照，贴标签

1. 关闭电池/外部电源的动力开关，再拔掉电源插头。
2. 拔ESP32的USB；舵机若有独立供电，也拔掉。
3. 等两只飞轮完全停下。不能用手按住它们停转。
4. 拍一张ESP32接线照、一张L298N信号排照、一张电源端子照，作为恢复依据。
5. 找到下面六根线，两端各贴标签。**以实际端点确认，不以颜色确认。**

| 标签 | 目前从哪里到哪里 |
|---|---|
| 14-ENA | ESP32 GPIO14 → L298N ENA |
| 25-IN1 | ESP32 GPIO25 → L298N IN1 |
| 26-IN2 | ESP32 GPIO26 → L298N IN2 |
| 27-ENB | ESP32 GPIO27 → L298N ENB |
| 21-IN3 | ESP32 GPIO21 → L298N IN3 |
| 22-IN4 | ESP32 GPIO22 → L298N IN4 |

**检查点：** 如果某根实际端点与表不一致，先追线并记下来；不要拔一根“看起来像”的线。不要拔底盘GPIO33的线，不要拔PS2的2/4/12/13。

## 第2步：按顺序拔六根旧信号线

1. **先拔27-ENB。** 从L298N ENB拔下，再从ESP32 GPIO27拔下，收好。检查ENB现在不再连GPIO27。
2. 拔25-IN1：从L298N IN1拔下，再从GPIO25拔下，收好，后面用于N20。
3. 拔26-IN2：从L298N IN2拔下，再从GPIO26拔下，收好。
4. 拔22-IN4：从L298N IN4拔下，再从GPIO22拔下，收好。
5. 拔21-IN3：从L298N IN3拔下，再从GPIO21拔下，收好并标“预留”。这根线有旧SDA故障历史，不拿来直接接新设备。
6. 拔14-ENA：从L298N ENA拔下，再从GPIO14拔下，后面改经分线排。

**现在不要上电。** L298N的四个IN和两个EN信号端均不再连原GPIO，原有EN到GND的10kΩ电阻保留。

不要动：L298N OUT1/OUT2到左130的两根线、OUT3/OUT4到右130的两根线；不要交换两台电机的极性。底盘、PS2及已核实电源线路保留。

## 第3步：认面包板孔，准备20–26排

1. 找面包板上印的a–j字母和数字，本文的`a20`就是a列、第20排。
2. 断电通断档确认：同一排a–e相通，f–j相通，中央槽两侧不通；相邻排不通。
3. 原底盘占第3–9排。本文使用原设计留空的20–26排，**先看实物有没有新增占用，有则不能覆盖**。
4. 左+轨已由ESP32 3V3供电；找其中一个空孔并确认它与原3V3轨连通。电源长轨可能中间断开，不能只看红线判断。
5. 找左GND轨两个空孔，确认它们与ESP32 GND和公共逻辑地相通。每个孔只插一根线。

## 第4步：先固定飞轮方向，再接共同使能

依次完成，做一根勾一根：

- [ ] 一根新线：**左3V3轨空孔 → a25**。
- [ ] 一根新线：**d25 → L298N IN1**。
- [ ] 一根新线：**e25 → L298N IN3**。
- [ ] 一根新线：**左GND轨空孔 → a26**。
- [ ] 一根新线：**b26 → L298N IN2**。
- [ ] 一根新线：**c26 → L298N IN4**。
- [ ] 用原14-ENA线或合适新线：**ESP32 GPIO14 → a20**。
- [ ] 一根线：**d20 → L298N ENA**。
- [ ] 一根线：**e20 → L298N ENB**。

确认：a20/d20/e20同排相通，所以同一GPIO14控制两EN；**GPIO27现在必须没有连接到ENB。绝不能把14和27两根GPIO互相并接。**

L298N两路EN的常高跳帽都取下。若原来已有两只10kΩ下拉可保留；本次在线改线采用合并EN共用一只10kΩ（b20→电阻→e26）。STBY另有独立10kΩ（c23→电阻→d26）。不要把EN或STBY直接短接GND。

四个IN固定为`高/低/高/低`，对应仓库三次成功试射的`DIR 1 1`。接好后仍须在无球低速试转时确认朝出口送球的方向；程序今后不再切换飞轮方向。

**L298N逻辑5V供电照原已核实接法，不能跟着IN1/IN3改成3V3。** 两台130的动力分支也不改成旧文档的12V；仓库只记录用户报告6V，实际端子电压仍需测量。

## 第5步：把空出来的25、26、22接到TB3

先把TB3固定，贴“送球N20”，仔细读每个端子的丝印。

- [ ] 原GPIO25的线：**GPIO25 → a21**；另用一根线 **e21 → TB3 AIN1**。
- [ ] 原GPIO26的线：**GPIO26 → a22**；另用一根线 **e22 → TB3 AIN2**。
- [ ] 原GPIO22的线：**GPIO22 → a23**；另用一根线 **b23 → TB3 STBY**。
- [ ] 新增一只10kΩ电阻：**一端c23，另一端d26**。这是TB3 STBY下拉。
- [ ] 一根线：**b25 → TB3 VCC**，得到3.3V逻辑电源。
- [ ] 一根线：**c25 → TB3 PWMA**，A路PWM使能固定高。实际低速PWM由程序在25/26上输出。
- [ ] 逻辑GND轨另一个空孔 → **f26**。
- [ ] **g26 → TB3 BIN1**；**h26 → TB3 BIN2**；**i26 → TB3 PWMB**，关掉不用的B路。
- [ ] TB3若有单独信号GND端：接逻辑GND轨独立空孔，并核对与板上功率GND的关系。

**TB3 STBY接22，不接底盘33！** 底盘停车时程序会拉低33，若共用它，N20就不能停车送球了。

TB3板上如果有将STBY硬拉高的焊桥/跳帽，应按模块说明解除，不能让GPIO22与板载常高连接冲突。

## 第6步：接N20电机线，动力正极最后接

1. 把N20暂时与弹匣/推球机构脱开，固定电机，避免第一次方向不对顶坏机构。
2. N20第一根**电机线** → TB3 **AO1/A01**，贴标签M1。
3. N20第二根**电机线** → TB3 **AO2/A02**，贴标签M2。
4. TB3 **功率GND → G0公共负极端子**，使用合适电源线，不靠面包板上的那根逻辑地承载电机电流。
5. N20动力电源负极 → G0。若已经是同一端子，不重复编造接口。
6. **TB3 VM正极先不接。** 先核实N20实物额定电压和启动/堵转电流，再选择适配电源，经过该分支保险和物理开关接VM。
7. TB3 **BO1/BO2留空并绝缘**，不能接地、接舵机或并到AO输出。

如果N20另有编码器排线，先不要接；只认出电机的M+/M−两根。编码器VCC不能接AO1/AO2。

仓库旧方案选过12V，但明确没有记录该N20的12V额定依据和堵转电流。**不要仅凭“N20”或“以前接过12V”给VM接电。** TB6612没有主动限流；当前官方正常工作表在VM≥4.5V时列每路1.0A，1.2A是绝对最大项、3.2A是限定短脉冲，不是长时间启动保证。额定电流不匹配时换适配驱动。

## 第7步：接仰角舵机；还没装舵机就跳过

1. 支撑住发射平台，把舵机连杆/舵盘负载卸开。上电中位可能转动，先不要让它拉着平台走全行程。
2. 找到舵机的S/Signal、V+、GND。常见黄/橙/白为信号，红为正，黑/棕为地；仍以实物说明为准。
3. **ESP32 GPIO27 → a24**；另一根线 **e24 → 舵机S**。
4. 舵机GND → 独立舵机供电负极分配端，并与G0共地；走电源线。
5. 舵机V+ → 适配的稳压电源正极。按仓库MG995/MG996R候选系列规划5V，**但具体实物及这路电源容量未核实前，先不接正极**。
6. 不从ESP32 3V3/5V针脚、L298N输出或TB3输出给舵机供电。

当前v3.1无舵机，跳过本节；`SERVO ON`被拒绝，SELECT无机构动作。下面仅说明旧版有舵机配置：初始1500µs；默认范围1400–1600µs，只是保守的调试起点，不对应已测平台角度。实物S端应接受3.3V信号，否则先增加适配电平转换，不能把5V直接接回GPIO27。

## 第8步：拿着这张表逐根核对

| 最终端子 | 应该接到哪里 | 不该再接到哪里 |
|---|---|---|
| L298N ENA、ENB | 两者都通GPIO14 | ENB不通27 |
| L298N IN1、IN3 | ESP32同源3V3 | 不通25、21 |
| L298N IN2、IN4 | 逻辑GND | 不通26、22 |
| TB3 AIN1、AIN2 | GPIO25、26 | 不接旧L298N方向脚 |
| TB3 STBY | GPIO22，另有10kΩ下拉 | 不接GPIO33或常高 |
| TB3 VCC、PWMA | 3V3 | 不接VM或5V |
| TB3 BIN1/BIN2/PWMB | GND | 不悬空乱接 |
| TB3 AO1/AO2 | N20电机两根线 | 不接编码器/舵机 |
| 舵机S | 当前未安装，GPIO27留空 | 不接H桥输出 |
| GPIO21 | 空闲，旧线收好 | 不接L298N IN3 |
| 底盘、PS2 | 原接法 | 本次不挪动 |

25排a/b/c/d/e分别是：3V3来源、TB3 VCC、TB3 PWMA、L298N IN1、L298N IN3，恰好五孔。26排左组与右组分别引入逻辑GND，不需要新增跨中央槽桥线。

## 第9步：配套程序先编译、再烧录；不要用旧程序

1. 新程序在包内 `firmware/robot/ChariotIntegrated/ChariotIntegrated.ino`。整个同名目录一起保留，里面的三个`.h`也必须在。
2. 选经典 **ESP32 Dev Module**，本次验证使用Arduino-ESP32 **3.3.12**。不是ESP32-S3。
3. **四轮、飞轮、N20动力及舵机电源全断开**，只给ESP32接USB。外部降压5V到ESP32的正极隔离，避免并联回供。
4. 确认正确端口后再由操作者上传；本次交付没有自动上传脚本，编译脚本只编译，不碰串口。
5. 串口监视器115200、换行，本次版本应看到 `BOOT ChariotIntegrated-v3.1-R1`。打开监视器可能复位，重新检查状态。
6. 发 `STATUS`。初始应有`hw=1`、`armed=0`、`chassis=0 fly=0 duty=0 feed=0 TB3=0 servo=0`。`ready=1`需要PS2在线并连续松开所有键、右摇杆回中5帧，约100ms；此时armed自动为1，不必按START。
7. **旧FlywheelSpinTest不能运行在新接线上**：旧程序会把GPIO27当飞轮PWM、25/26/22当飞轮方向，可能误动舵机或送球机构。

## 第10步：只给逻辑供电，先测不该动的地方

黑表笔接模块GND，红表笔在模块端子测，不只量电源板：

| 测点 | 静止时应看到 |
|---|---|
| L298N ENA/ENB | 两者约0V |
| L298N IN1/IN3 | 两者约3.3V |
| L298N IN2/IN4 | 两者约0V |
| TB3 VCC/PWMA | 两者约3.3V |
| TB3 STBY/AIN1/AIN2 | 三者约0V |
| 底盘D1/D2 STBY | 约0V |

按ESP32复位键再检查一次。若ENB仍有常高，先查跳帽；若TB3 STBY常高，查焊桥或错线。任何异常都断电处理。PWM频率/舵机脉宽不能靠万用表平均值确认，有条件用示波器/逻辑分析仪测。

## 第11步：逐个试，先别装小球

每次改插头都全断电；每一阶段只接被测机构动力，其余动力保持断开。PS2保持在线、按键松开且右摇杆回中。

1. **N20方向**：电机脱开机构。满足电压/电流条件后接TB3 VM。发`ARM`，再发`JOG 1 100`，仅30%占空比、100ms。观察M1/M2极性对应方向；发`STOP`。需要反向时松键重新就绪、`ARM`，距上次停止至少800ms后发`JOG -1 100`。不动时先查电压、电流/机构阻力，不马上加大占空比。方向确认后才能装机构。
2. **飞轮**：无球、护罩固定，只接飞轮动力。发`ARM`、`FLY 30 3000`，确认两台都转且摩擦面朝球出口。指令结束后仍会滑行。逐级测试电流/温升后再使用手柄100%输出；不能把之前三次试射算作本次改线后的验收。
3. **舵机跳过**：当前无舵机，v3.1禁用GPIO27脉冲；不要执行旧版舵机测试。
4. **停车对接**：底盘停车，点按R1输出一次150ms/30%脉冲，松开仍到时停止，不要求先按R2；若飞轮已在转则需预转至少2.5秒。当前值不保证滑轨到位。标定后改`RobotConfig.h`中的方向、时长和占空比，重新编译。
5. **停止/失联**：松R2应撤销飞轮输出，以及在该次飞轮运行期间启动的N20动作；独立R1动作仍运行到固定时限。方向键/右摇杆仍有驾驶输入时底盘可继续行驶；圆圈、串口STOP或手柄有效帧中断≥150ms应撤销全部电机输出，N20到时也应自行撤销。不要在人手靠近机构时做失联试验。

发热异常、异味、冒烟、持续嗡鸣不转、到位不停、严重振动、主控反复复位，都立即用物理开关断动力；完全停稳后再查。**软件PWM不是限流保护，N20未装到位开关时也不是闭环定位。**
