# 手柄驾驶与双飞轮整合固件

基于最近使用的 MecanumPS2Dpad，保留其全部驾驶功能、轮向标定、100% 底盘目标占空比、加速斜坡及 300ms 换向等待。打开同目录 MecanumPS2Flywheel.ino，选择 ESP32 Dev Module（esp32:esp32:esp32），Arduino-ESP32 3.x。

| 操作 | 功能 |
| --- | --- |
| 上 / 下 | 前进 / 后退 |
| 左 / 右 | 左 / 右平移 |
| 上下方向 + 左右方向 | 斜向移动 |
| 右摇杆左 / 右 | 按幅度左转 / 右转；可与方向键叠加 |
| 松开方向键且右摇杆回中 | 底盘撤销输出 |
| 按住 R2 | 两个飞轮立即以 100% 占空比运转 |
| 松开 R2 | 两个飞轮撤销输出，惯性滑行停止 |
| 圆圈 / 串口 STOP | 全车停止，松开全部按钮后重新就绪 |

开机和停止后，先松开所有按钮并让右摇杆回中，收到 5 个有效无按键帧（约 100ms）后 ready=1。R2 可重复按下，无单次时限；支持边驾驶边启动飞轮。不需要 START/L1，右摇杆横轴控制转向，左摇杆和右摇杆纵轴不参与控制。右摇杆中位 128，死区 ±20；开机、急停及失联恢复均需摇杆回中并松开按钮。

底盘和 PS2 接线不变。飞轮1 EN/IN1/IN2=14/25/26；飞轮2 EN/IN3/IN4=27/21/22。飞轮使能脚直接输出恒高实现 100% 占空比，恒低实现关闭，不占用或改变底盘 LEDC 0–7 通道。L298N ENA/ENB 跳帽保持移除，保持现有共地和使能下拉。

飞轮方向沿用最近测试 DIR 1 1，即 IN1/IN3 高、IN2/IN4 低；实际是否向球道出球方向对转尚需现场观察。需要改极性时修改源码顶部 FW1_DIRECTION / FW2_DIRECTION（+1 或 -1）。

释放 R2 在下一次有效轮询（通常约 20ms）撤销输出；无效帧立即停机、150ms 无有效帧锁定，保留 1 秒看门狗。断联后需先松开全部按钮。若无线接收器重复旧有效帧，固件无法识别无线侧断联，需实物验证。

115200 串口：STATUS 显示固件版本、手柄状态、四轮指令、fire 和两个 FW 使能百分比；STOP 停止全部电机。这些是指令/引脚状态，不是实测轮速。

主机验证：tests/run-combined-tests.cmd，覆盖原底盘回归、R2 满输出、松手、同时驾驶、急停、失联、重连和初始化失败。实物运行与出球效果需现场验收。


## v2 右摇杆转向（2026-10-17）

自动请求模拟模式（73/79）；数字模式 41 不读取摇杆尾部字节，空闲时每 2 秒重试配置。STATUS 增加 RX、turn、analog；analog=1 才有独立摇杆数据。若一直为 41，可按手柄 ANALOG/MODE 键切换。模式切换重新要求回中，防止切换时突然转动。

混控加入旋转分量，超限统一归一化；保留原加速斜坡和换向等待。摇杆回中只取消转向，若仍按住方向键则继续平移。飞轮操作不变。

模拟模式协商参考 [PS2X 作者实现](https://github.com/madsci1016/Arduino-PS2X/blob/master/PS2X_lib/PS2X_lib.cpp)。
