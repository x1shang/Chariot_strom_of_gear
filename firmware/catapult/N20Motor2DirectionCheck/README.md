# L298N：2号 N20 电机正转3秒方向测试

日期：2026-10-14。版本：`N20Motor2Fwd3s-v2`。

导航：[仓库总入口](../../../README.md) · [L298N 接线](../../../docs/抛投装置-L298N双N20接线与GPIO分配.md)

用户定义：**2号电机驱动转轴、拉绳蓄力；1号电机控制2号电机的位置以实现释放**。用户要求在当前激发态只测试2号电机正转3秒，不实现或执行1号释放动作。

| 通道 | 输出端 | GPIO / 行为 |
|---|---|---|
| 1号释放电机 | OUT1/OUT2 | ENA=14 始终低；IN1=25、IN2=26 始终低 |
| 2号转轴电机 | OUT3/OUT4 | ENB=27；正转定义 IN3=21 高、IN4=22 低，100% 使能 |
| 底盘 | 双 TB6612 | STBY=33 始终低；本测试固件不含手柄行驶控制 |

ENA/ENB 常高跳帽取下，各 EN 保留10kΩ下拉；用户已确认接线、烧录准备时动力关闭/USB保留，以及3秒测试仍有可用行程。N20 的12V动力与底盘动力分别提供。

串口115200，命令以换行结束：

- `STATUS`：读取固件版本、两路使能、方向脚、运行/已使用标记及软件计时。
- `FWD3S`：2号电机按电气正转运行3000ms，随后 ENB拉低、IN3/IN4拉低。每次上电只允许一次，执行过或中途停止后拒绝重复命令。
- `STOP`：立即撤销2号使能，1号及底盘继续禁用。

上电/复位不会自动运动；需要主机明确发送 `FWD3S`。换向与1号电机运动命令未实现。运行循环不使用3秒阻塞延时，持续检查到期与STOP；另设置1秒任务看门狗。软件计时不是独立硬件限位或真实角度反馈。

v2 增加 GPIO 回读互锁：若1号使能/方向、底盘 STBY 或2号使能/方向回读与当前应有状态不一致，锁定 hw=0 并撤销输出，拒绝运动。第一版烧录后曾读到空闲 ENA=1、ENB=1，实际3秒命令未执行；这一现场异常保留在日志中，不能以程序写入 LOW 代替接线/模块端电压检查。

使能撤销是滑行停止，**不会主动保持转轴位置**。这里的正转是电气方向，实际拉绳/放绳方向须由用户观察确认；本次不自动释放或复位机构。

烧录应在L298N动力关闭时进行。烧录后先读状态确认 `hw=1 used=0 running=0 ENA=0 ENB=0 STBY=0`，恢复动力后才执行这一次运动。代码和测试范围见实际测试记录，不由串口输出推断机械运动。

本固件只证明**电气通路**。同日用户实机抛投试验报告机构四项失败（电池像是断路、3D 打印孔过大滑齿、卷线轴无半月形杆导致齿轮脱落、人力满行程下抛射初始角度仍接近水平），说明电气可用不等于机构可用，详见[实机抛投失败记录](../../../docs/logs/2026-10-14-throw-test/README.md)。6 次复现与哈希见[测试记录](../../../docs/logs/2026-10-14-n20-motor2-check/README.md)。
