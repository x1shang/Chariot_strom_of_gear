用户要求：正转定义为从输出轴端看顺时针；2号蓄力机运行3000ms，停止2号后，1号运行500ms，最后全部停止，不循环。

| 设备 | 接线 | 本次极性 |
|---|---|---|
| 1号 | OUT1/OUT2；ENA=14、IN1=25、IN2=26 | 用户确认 IN1高、IN2低为逆时针；顺时针用 IN1低、IN2高，即d1=-1 |
| 2号蓄力机 | OUT3/OUT4；ENB=27、IN3=21、IN4=22 | 用户确认 IN3高、IN4低为顺时针 |
| 底盘 | STBY=33 | 始终禁用，不含手柄行驶 |

继承已测试的100%使能方式，未改动力供电。取下ENA/ENB常高跳帽，各路保留下拉。程序撤销EN为滑行停止，不提供轴位置保持或零速度检测。

串口115200，命令以换行结束：

- `STATUS`：状态、方向极性、两路使能/方向回读及软件计时。
- `DIR -1 1`：按用户确认的两台顺时针极性设置；指定电机1、2各自的正转极性；每个参数可为1或-1。1表示该路第一个IN高、第二个IN低；-1交换。设置不运动，只在本次尚未RUN时可用。
- `RUN`：只执行一次完整序列。必须先DIR且硬件回读正常；执行过或中途STOP后拒绝重复RUN。
- `STOP`：撤销两路使能，取消后续阶段。未知/过长命令亦停止。

默认上电静止且清除方向设置；不因烧录、开串口或复位自动运动。固件分阶段非阻塞计时，先关闭2号桥、检查两路静止回读，再打开1号桥，无两路同时使能。1秒任务看门狗及GPIO回读故障使整套动作停止。

主机工具：[n20_sequence_once.py](../../../host/n20_sequence_once.py)。只发送一次RUN，不复位、不重试，结束或异常时STOP，并保存日志。仿真覆盖3秒/0.5秒边界、四种方向组合、两路不重叠、切换边界STOP不释放、回读故障、重复命令拒绝、启动静止与计时回绕。

用户已确认首次试验1号为逆时针，未来两台顺时针采用DIR -1 1，主机默认d1=-1、d2=1。历史串口记录仍保留原始试验极性。后续仅2号测试已将板上恢复为独立N20Motor2DirectionCheck固件，本顺序源码保留。
