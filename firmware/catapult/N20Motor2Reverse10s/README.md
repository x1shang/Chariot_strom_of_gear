# L298N：仅2号逆时针运行10秒

日期：2026-10-14。固件：`N20Motor2Ccw10s-v1`。

用户要求仅2号逆时针运行10秒。沿用已确认的通道接线，取2号顺时针极性的反向：**IN3=21低、IN4=22高、ENB=27高**，100%使能。1号ENA=14与IN1=25/IN2=26始终低，底盘STBY=33始终低。

导航：[总入口](../../../README.md) · [接线](../../../docs/抛投装置-L298N双N20接线与GPIO分配.md) · [本次测试记录](../../../docs/logs/2026-10-14-n20-motor2-ccw10s/README.md)

串口115200，命令以换行结束：

- `CCW10S`：仅2号运行10000ms后撤销ENB与方向输出，每次上电只允许一次。
- `STOP`：立即撤销2号使能，1号与底盘继续禁用，不自动重试。
- `STATUS`：版本、默认静止/运行状态、两路使能、方向脚、STBY与软件计时。

上电/复位不自动运动。程序使用非阻塞计时、GPIO回读互锁和1秒任务看门狗；故障、未知或过长命令会停止。撤销使能为滑行停止，不提供机械位置保持。

从已经验证的独立2号3秒固件派生，仅更改运行方向、10000ms截止时间和对应命令/版本，保留1号与底盘禁用行为。实际固件仿真覆盖逆时针输出、10秒到期和计时回绕、STOP、重复命令拒绝、默认静止与回读故障。

主机工具：[motor2_counterclockwise_once.py](../../../host/motor2_counterclockwise_once.py)。检查新固件静止状态，留5秒准备，仅发一次CCW10S；检查逆向电平、时限与停止，异常时STOP，不复位或重试。
