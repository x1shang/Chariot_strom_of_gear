# L298N：双 130 摩擦飞轮软启动转动测试

日期：2026-10-17。版本：`FlywheelSpin-v2-100`。

更新：用户反馈 30% 测试时未看到转动，要求逐级测试至 100%；本版把硬上限提高到 100%，默认仍为 30%，保留软启动、限时、一次/上电和上电静止。**100% 是连续使能，不是电机额定电压保证。** 用户说明降压模块接到 L298N 的 `5V` 端、跳帽全部断开；`5V` 为逻辑电源，`VS/+12V` 动力端是否另有供电尚待确认。此前串口流程通过不等于实际转动通过。

本固件是**新方案（原驱动板 L298N + 两个 130 电机摩擦飞轮）的第一则测试程序**。旧方案（L298N + 双 N20 卷线蓄力）因扭矩过大把电机撕裂而终止；旧程序全部保留并归档，见上。

| 通道 | 输出端 | GPIO / 行为 |
|---|---|---|
| 130-1 左飞轮 | OUT1/OUT2 | ENA=14 走 **5kHz PWM 软启动**；方向 IN1=25、IN2=26 |
| 130-2 右飞轮 | OUT3/OUT4 | ENB=27 走 **5kHz PWM 软启动**；方向 IN3=21、IN4=22 |
| 底盘 | 双 TB6612 | STBY=33 **全程为低**；本固件不含手柄行驶控制（**板上烧了本固件，底盘不行驶**） |

两侧飞轮同时启停，同一占空比。两轮必须**反向旋转**才是有效发射方向，但「电气极性 ↔ 观察到的转向」本轮未确认，由 `DIR` 设定为实验值。

## 命令（串口 115200，以换行结束）

| 命令 | 行为 |
|---|---|
| `STATUS` | 版本、`hw`、`used`、`dirs`、`phase`、`d1/d2`、`pct/ms`、**两路 EN 的 PWM 回读 `DUTY1/DUTY2`**、四个方向脚、`STBY`、计时 |
| `DIR <d1> <d2>` | 设定两路极性（各取 `1` 或 `-1`），不产生运动；`SPIN` 之后不可再改 |
| `SPIN [duty] [ms]` | 两侧同时软启动到 `duty`% 并保持，到时关断。缺省 `30 3000`；`duty` 限 1–100，`ms` 限 1–10000。**每次上电只允许一次** |
| `STOP` | 立即把两路 EN 置 0 并撤销方向（滑行停止），飞轮靠惯性继续转 |

`pct`/`ms` 的缺省值是 30% / 3000ms；`ms` 从 `START` 起算，**包含 1200ms 爬升段**。非法命令一律停机并回答 `ERR ...; stopped`。

## 设计要点与理由

- **软启动（1200ms 线性爬升）**：飞轮是惯性负载，起始电流接近堵转电流。爬升期间平均电压被占空比压低，起始电流约为「占空比 × 堵转电流」，把冲击摊到整个加速过程。
- **占空比硬上限 100%、默认 30%**：按用户要求从 v1 的 60% 提高到 100%，供逐档诊断使用。130 电机的铭牌与额定电压未记录，占空比不限制电源脉冲幅值；本次用户更正降压模块为 5V，仍须区分逻辑 `5V` 与动力 `VS` 端子的供电。
- **PWM 5kHz / 8bit**：L298 是双极型桥，开关沿慢、开关损耗随频率上升；底盘 TB6612 用的 20kHz 是 MOS 输出的取值，不能照搬。底盘在本固件中全程禁用，因此本固件用 LEDC 通道 0/1 不冲突；**将来并入行驶固件时必须重新统一分配通道与定时器**。
- **EN 现在是 PWM 脚，回读方式随之改变**：`DUTY1/DUTY2` 是 `ledcRead()` 的**外设（已命令占空比）回读**，**不能证明引脚实际电平或电机端电压**。占空比为 0 时固件仍读一次引脚电平，用于发现「EN 跳帽没取下来 / 外部上拉」这类异常。方向脚与 STBY 仍是真实引脚电平回读。
- **启动时的引脚电平检查在 LEDC 接管之前**：先按普通输出把 8 个脚拉低并回读，再挂 PWM，因此旧固件里出现过的「空闲 ENA=1、ENB=1」不会被漏掉。

## 安全与互锁

- 上电静止，**不会自动转动**；必须显式发 `DIR` 再发 `SPIN`。
- 每次上电最多一次；执行过、中途 `STOP` 过或出错后拒绝重复，必须复位。
- 任一方向脚、STBY、或两路 EN 的回读与应有状态不符 → 立刻撤销输出、锁 `hw=0` 并打印 `FAULT`，不再接受运动命令。
- 命令溢出（一行超过 31 字符）→ 停机。
- 1 秒任务看门狗；串口无输入不影响转动计时。
- `DONE` 与 `STOP` 都会打印 **`COAST`**：**电气输出已撤销，飞轮仍在惯性旋转，不是已经停转**。撤 EN 是滑行停止，不抱死，也没有转速/位置反馈（本方案无编码器）。
- 烧录、接线、拔插时**必须关闭动力**，只留 USB 与逻辑 5V。动力侧要有物理断电开关；飞轮旋转面不得站人。

## 验收口径（本固件能证明什么、不能证明什么）

**能证明**：固件按命令给出了指定的方向电平与占空比、软启动按预期爬升、到时/STOP/异常时两路 EN 归零、每次上电只执行一次。

**不能证明**：130 电机是否真的接在 OUT1/OUT2 与 OUT3/OUT4、电机是否真的转动、转向、转速、电流、温升、飞轮是否装好、两轮是否真的对转。这些需要现场观察与仪表，属[接线文档](../../../docs/抛投装置-双130摩擦飞轮接线与GPIO分配.md) §11 的验收步骤。
